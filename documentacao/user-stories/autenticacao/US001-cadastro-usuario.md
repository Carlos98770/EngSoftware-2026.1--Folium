# US001 - Cadastro de novo usuário

## Prioridade
Alta

## História

Como visitante,
quero criar uma conta na plataforma,
para que eu possa acessar os recursos de empréstimo e gestão de livros.

---

## Critérios de aceitação

- Visitante preenche nome, email e senha
- Email duplicado retorna mensagem de erro clara
- Após cadastro, usuário é redirecionado automaticamente para a home logado

---

## Regras de negócio

- O email deve ser único
- A senha deve ser armazenada criptografada

---

## Fluxo principal

1. Usuário acessa tela de cadastro
2. Preenche formulário
3. Sistema valida os dados
4. Sistema cria conta
5. Sistema autentica automaticamente
6. Usuário é redirecionado para home
