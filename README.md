## Sobre o Projeto

### Título
Folium

### Descrição
Folium é uma plataforma web para gestão de empréstimos de livros entre usuários. Permite cadastrar livros, controlar disponibilidade, realizar e devolver empréstimos, e administrar usuários com diferentes níveis de acesso.

## Como clonar ou baixar

Você pode obter este repositório de três formas:

### Clonar via HTTPS

```bash
git clone https://github.com/Carlos98770/EngSoftware-2026.1--Folium
```

Isso criará uma cópia local do repositório em sua máquina.

### Clonar via SSH

Se você já configurou sua chave SSH no GitHub, pode clonar usando:

```bash
git clone https://github.com/Carlos98770/EngSoftware-2026.1--Folium
```

Isso criará uma cópia local do repositório em sua máquina.

### Baixar como ZIP

1. Acesse a página do repositório no GitHub:
   [https://github.com/Carlos98770/EngSoftware-2026.1--Folium](https://github.com/Carlos98770/EngSoftware-2026.1--Folium)
2. Clique no botão **Code** (verde).
3. Selecione **Download ZIP**.
4. Extraia o arquivo ZIP para o local desejado em seu computador.
